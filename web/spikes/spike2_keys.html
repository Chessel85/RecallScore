Spike 2: which keys reach the page

Below are three test widgets, each a different kind of control. Tab to one, check your screen reader has switched to focus mode, then press each planned key. Every key the page receives is spoken straight away ("reached: Control L"). Silence, or the browser or screen reader doing something else, means the key was lost. The page blocks the browser's own action for every planned key, so Ctrl+P should not open Print, for example.

Alt on its own and F10 normally open the browser menu. Press Escape if that happens.

When you have tried every key on all three widgets, copy the report. The results table at the end shows what reached each widget.
