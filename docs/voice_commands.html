Recall Score Voice Commands

These are the spoken commands recognized when voice control is on. Turn voice control on or off with Alt+Enter, or Options > Toggle Voice Control.

Voice Control settings are in Options > Voice Control Settings… (Ctrl+Shift+R) to set the microphone and how confident a command must be before it is acted on.

A short confirmation sound plays whenever a command is recognized and acted on.

Commands are limited to the those listed here.

Playback

Say What it does
play Starts or resumes playback
stop Stops playback
pause Pauses playback
slower Reduces the playback tempo, like S
faster Increases the playback tempo, like F
default speed Resets the playback tempo to the score’s own tempo, like D

Navigation

Say What it does
forward, or right Moves right one note, like the Right Arrow key
back, or left Moves left one note, like the Left Arrow key
next bar, or next measure Moves to the start of the next bar
previous bar, or previous measure Moves to the start of the previous bar
home Moves to the first note
end Moves to the last note
go to bar number, or go to measure number Jumps to that bar. Only bar numbers that exist in the loaded score are recognized, including bar zero for a pickup bar

Looping and Lead-In

Say What it does
looping on, or loop on Turns looping on
looping off, or loop off Turns looping off
loop length number Sets the loop length in bars, from one to sixty four
lead in on Turns the lead-in count-in on
lead in off Turns the lead-in count-in off

Note Attributes

Say What it does
attribute number Speaks that row of the Note Attributes region for the selected notes without moving focus, like Ctrl+1 to Ctrl+9 in the Note region. Recognizes one to nine

Saying Numbers

Say numbers as words, without “and”: for example “go to bar one hundred five”, not “one hundred and five”.
