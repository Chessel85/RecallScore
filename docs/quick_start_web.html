Recall Score Web Version Quick Start Guide

  • Go to https://chessel85.github.io/RecallScore/app/ in a web browser. The first visit downloads the program and its sounds, so allow a little while.
  • Browsers only allow sound after a key press or click, so the first key you press on the page starts the sound.
  • Open a score with the “Open a score” control at the top of the page, with Menu > File > Open a score, or by dropping a file onto the page. The web version opens MusicXML (musicxml, xml, mxl), Guitar Pro (gp) and midi (mid, midi) files.
  • Press M to open the menu from anywhere. Use the arrow keys to move through it, Right or Enter to open a menu, Left to close it. Press F1 for a list of every key.

Once loaded, there are six regions which can be reached with tab and shift+tab:

  • Score Information. A list containing information about the score.
  • Parts. A list of the parts in the score. Each can be expanded and collapsed with right and left arrow keys to show the staves. Each stave can also be expanded or collapsed to show the voices on that stave.
  • Notes list. The active notes present at the current position. This is where you will spend most of your time.
  • Attributes list. Extra information about each note selected in the note list.
  • Performance Information. Information on how to perform the piece based on the current position within the score e.g. Repeat bars.
  • Status. The current position and settings, which the desktop version shows on its status bar.
  • Use keyboard quick navigation keys of Z, X, C, V, B and N to jump to any area.

Playback with:

  • Press spacebar to hear the music. Press control+space to pause. Spacebar also restarts or stops playback.
  • Use S to slow down playback; F to go faster or D to return to the original speed.

In the notes list:

  • Use left and right arrow keys to move through the score.
  • Use control and the left and right arrow keys to move a bar at a time.
  • Type a number and hit enter to jump to that bar number. Backspace cancels a typed number.
  • If there is more than one note in the note list, use up and down arrow keys to select individual notes.

From the attributes list:

  • Use up and down arrow keys to get more information about selected notes.
  • Press Shift+F10 (or the Applications key) on any attribute and use the down arrow key to choose options to add the attribute for notes in the current voice, stave or part.
  • Use Attribute Management in the Options menu (Control+Alt+A) to adjust the order the attributes are displayed both for notes and the attributes list.

Parts list:

  • Use this list to filter which notes are shown from parts, staves and voices.
  • Press F8 to toggle mute for a part, stave or voice.
  • Press F9 to toggle solo for a part, stave or voice.
  • Muted notes are not displayed in the note list. Soloed notes are always shown in the notes list overriding a mute.
  • Alt+F8 and alt+F9 unmute and unsolo all.

Some desktop keys are used by the browser, so a few commands have a different key on the web, for example Find is Control+Shift+F. The menu and F1 always show the key a command really has.

Your settings are kept in the browser, so they are lost if you clear the site’s data.

Explore the File, Edit, Parts, Navigation, Playback, Options, Tools and Help menus for more features.

Full details are in the Recall Score Web Version User Guide.
