T2 (high, macOS) — Two shortcuts collide with reserved macOS system keys                                                
                                                                                                                        
Files: widgets/menu_builder.py:422 (Ctrl+Space, Pause), widgets/menu_builder.py:562 (Ctrl+M).                           
                                                                                                                        
Qt swaps Ctrl for Cmd on macOS by default. That makes Pause into Cmd+Space, which Spotlight takes at the system level   
before the app sees it, and Ctrl+M into Cmd+M, which is the standard macOS Minimize on the Window menu. Neither will    
work on a Mac, and Cmd+M will minimise the window instead.                                                              
                                                                                                                        
Fix: platform-branch both in menu_builder (the file already has the shortcut strings in one place). Ctrl+Alt+Space (Play
 Metronome) survives the swap and is safe. This is the concrete form of what the last report could only flag as "needs  
checking".

T4 (medium) — Bare-letter shortcuts still suppress list type-ahead                                                      
                                                                                                                        
Files: main_window.py:301-303 (F/S/D), plus Z/X/C/V/B, 0-9.                                                             
                                                                                                                        
Unchanged from S10. F, S, D and the digits are WindowShortcuts, so Qt's native first-letter type-ahead is dead in all   
five list regions. In a score with hundreds of note rows this is a standard Windows behaviour a screen-reader user      
brings with them and does not get. Still a design decision rather than a bug, but it is now the single biggest remaining
 gap in the screen-reader-UX score.
